
# Admin Dashboard

A dashboard interface built with HTML and CSS as part of my journey through [The Odin Project](https://www.theodinproject.com/).


## Built With

* HTML5
* CSS3
* CSS Grid
* Flexbox
* Font Awesome icons

## About the Project

The goal of this project was to recreate an admin dashboard from a visual reference provided by The Odin Project, with a strong focus on CSS Grid for the overall page layout.

I used CSS Grid extensively to structure the dashboard and Flexbox where it was useful for aligning and arranging smaller elements within sections.

## What I Learned

* Creating multi-section layouts with CSS Grid.
* Understanding grid rows, columns, tracks, and item placement.
* Combining CSS Grid and Flexbox to organise page layouts and align content.
* Translating a visual reference into a functional webpage.
* Debugging layout issues and understanding how grid items behave within their containers.

## Reflection

This project was a turning point in my CSS learning journey. After years of learning and practising web development, this was the first time I truly understood CSS Grid and how its layout system works.

Working through the challenges, experimenting with different properties, and debugging my mistakes helped me develop a much clearer understanding of layout design.

There are still some alignments I would like to improve, and I may revisit them later. For now, I'm grateful for how far I've come, proud of what I've built, and motivated to keep learning and getting better.

# Admin-Dashboard
An admin dashboard built with HTML and CSS, focusing on CSS Grid for page layout and component positioning. A project from The Odin Project's Intermediate HTML and CSS curriculum.

Project Overview

The goal of this project is to recreate a dashboard interface from a provided reference image while practising CSS Grid and strengthening my understanding of page layout.

Acknowledgements

This project was completed as part of The Odin Project, an open-source curriculum for learning web development.
